# 📱 Gelişmiş Telefon Rehberi Sistemi

Modern ve kullanıcı dostu arayüzü ile geliştirilmiş bu telefon rehberi uygulaması; kişi kayıtlarını kolayca yönetmenizi, hızlı erişim sağlamanızı ve verilerinizi güvenli bir şekilde saklamanızı amaçlamaktadır.  

C# ve SQL Server teknolojileri kullanılarak geliştirilen sistem, klasik rehber uygulamalarına göre daha kapsamlı ve pratik çözümler sunar.

---

## 🚀 Uygulama Özellikleri

✨ Yeni kişi kaydı ekleme  
✨ Mevcut kayıtları güncelleme  
✨ İstenilen kişiyi hızlıca arama  
✨ Gereksiz kayıtları silme  
✨ Tüm kişileri listeleme  
✨ Telefon numarası veya isim ile filtreleme  
✨ SQL Server veri tabanı desteği  
✨ Hızlı ve sade kullanıcı arayüzü  

---

## 🎯 Projenin Amacı

Bu proje, kullanıcıların kişi bilgilerini güvenli, hızlı ve düzenli bir şekilde yönetebilmesi için geliştirilmiştir.  
Tüm veriler merkezi veri tabanında tutulur ve kullanıcılar istedikleri kayda saniyeler içerisinde ulaşabilir.
